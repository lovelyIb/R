# 추론통계
데이터 : 정보를 위한 기초적인 자료
정보 : 데이터를 잘 가공해서 그것에 대한 결과를 보기 쉽게 만든 것

중심경향 / 변동성

이상점과 극단값 => 극단값이 이상점이 되는건 연구자 나름. 

추론통계 : 데이터의 현상을 파악

귀무가설 / 대립가설
표준정규분포에서 p-value가 평균에 가까우면 귀무가설을 기각할 충분한 근거가 없음, 멀면 충분한 근거가 있음

t-test / z-test >> p-value 검출

분산의 분포를 통해서 변동성을 도출할 수 있음

chi square-test
적합도 검정 : 수치적인 분포가 얼마나 일치하냐
독립성 검정 : 범주형 변수가 얼마나 관련성이 있나

f-test

그룹을 비교할 때 세 개 이상의 그룹을 비교? >> 분산분석(ANOVA) - 일원분산분석 / 이원분산분석

독립변수 : 가설의 원인, 종속변수에 영향을 미침 (카페의 분위기 등등..)
종속변수 : 가설의 결과, 독립변수로 영향을 받음 (카페의 만족도)

# 머신러닝
데이터로부터 패턴을 학습하고, 새로운 데이터에 대해 예측/분류/생성 등을 수행

추론통계는 값이 일정함. 머신러닝은 그렇지 않음. (train data, test data 때문)

추론통계 : 현상을 파악
머신러닝 : 데이터를 예측

>## 지도학습 
회귀 >> 연속적인 데이터를 가지고 수치를 예측

회귀분석 : 변수들 사이의 특성을 나타냄. 회귀직선을 만드는거.

 y 종속변수 beta_0 상수 beta_1 회귀계수 x 독립변수 epsilon 오차항
 
 y = beta_0 + beta_1 * x + epsilon
오차가 가장 작은 직선을 그리는게 핵심.
예측할 수 없는 사항을 오차항으로 두는것.

p-value가 낮으면 독립변수는 종속변수를 유의미하게 설명하지 않는다. 물론 R^2값이 낮으면 이 모델은 설명력이 없음.

상관관계 = 상관계수를 검사 cov(X,Y)

MAE (절대값) - 평균절대오차

MSE (제곱) - 평균제곱오차

RMSE (제곱) - 평균오차

회귀모델에 있어서는 정확도보단 MAE MSE RMSE 같은 검증값을 사용
