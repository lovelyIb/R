>## 지도학습

회귀분석 : 변수들 사이의 특성을 나타냄. 회귀직선을 만드는거.
1. 단순회귀분석 : 하나의 독립변수
2. 다중회귀분석 : 여러개의 독립변수


 y 종속변수 beta_0 상수 beta_1 회귀계수 x 독립변수 epsilon 오차항
 
 y = beta_0 + beta_1 * x + epsilon
오차가 가장 작은 직선을 그리는게 핵심.
예측할 수 없는 사항을 오차항으로 두는것.

p-value가 낮으면 독립변수는 종속변수를 유의미하게 설명하지 않는다. 물론 R^2값이 낮으면 이 모델은 설명력이 없음.

상관관계 = 상관계수를 검사 cov(X,Y)

## 로지스틱 회귀분석
이분류 하는 모델
시그모이드 함수 0과 1사이의 값.
임계값 (나누는 값)
종속변수가 2가지의 값만을 가짐

왜 R^2와 RMSE가 없는가. 
회귀에서 수치형에서 이 둘이 설명력을 나타냈다면 
분류에서 범주형으로 정확한 임계값으로 나눌 수 있음. (정확도)
그래서 범주형 분류 분석을 할때는 설명력보다 정밀도, 재현률, 정확도, F1 score 사용

정밀도 : 우리가 상자에서 원하는것을 뽑았다. 뽑은 거에 대해서 계산만 함. 맞게 꺼낸 A / 전체 꺼낸수
재현율 : 실제로 있는 A개수에서 뽑은거 계산. 맞게 꺼낸 A / 전체 A수

정밀도와 재현율을 같이 높이기 위해선 ?? >> 이런 모델을 찾는게 핵심 (정밀도와 재현율 기말고사때 냄 식은 적어도됨)

ROC 커브를 그려서 아래면적(AUC)를 구함 => 1에 가까울수록 좋음
y 축 재현율 값이랑 같음 (진짜를 얼마나 찾았는가)
x 축 (가짜를 얼마나 착각했는가)

Mcnemar 대칭적인지 대칭적이지 않은 데이터인지 판단용 0.05 > 대칭적
정밀도 재현율은 혼돈행렬 구해서 식 대입
